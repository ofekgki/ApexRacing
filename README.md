# ApexRacing

Final Project for a Application Development course, in Afeka - the academic college of Engineering in Tel Aviv.

# Overview

Apex Racing is an Android application built for Formula 1 fans, combining race Result, fantasy team management, community interaction, into one immersive mobile experience.

Developed in Kotlin using Android Studio, the app integrates Firebase services and external F1 API to deliver real-time content, personalized user profiles, and an interactive racing-focused platform.

Video demonstration of the app included in the project files.

# Features

-   **Favorite Driver & Constructor Selection**
-   **F1 Race Calendar with Circuit Information**
-   **Live Driver and Constructor Standings**
-   **Community Posts and User Interaction**
-   **Standings Data for all previous seasons**
-   **Fantasy Team Management System**
